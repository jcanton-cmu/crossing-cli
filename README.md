# Crossing-CLI
Just run the exe and you can add a `-h` flag to anything to get instructions.

Put the executable in the parent folder of [crossing numbers of the complete graph](https://github.com/Crossing-Numbers-SAT-CMU/crossing_numbers_of_the_complete_graph) alongside the `generators.json` file and it should automatically run correctly.ls
